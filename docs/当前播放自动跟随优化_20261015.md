# 当前播放自动跟随优化（2026-10-15）

用户要求：黑幕工具默认面向当前播放内容，不需要选择或手动指定播放器。

## 实现范围

- 首页删除可见播放器选择；定时与黑幕编辑仅展示当前识别到的内容，不提供应用目录或手动选择。
- 黑幕外仅唯一PLAYING媒体会话能成为自动控制目标；旧PAUSED/NONE和多个并行PLAYING不冒充可靠当前目标。无目标时禁用媒体控制，黑幕及固定返回仍可用；不注入全局媒体键。
- 同一次黑幕内允许保留其暂停目标以便恢复播放；退出/创建失败/会话销毁清理目标。新唯一PLAYING来源优先于旧暂停目标。
- 定时命令只固定自己的原token，不修改全局当前播放源；确认时来源变化不能误提交暂停/片尾。固定返回无需目标，来源已变化时不把偏好写回旧应用。
- 不新增权限，不读取前台应用使用记录，不启用额外无障碍权限。系统未提供有效媒体会话时，不能宣称已识别该App或支持暂停。

## 验收标准

1. 主界面、定时、黑幕均不要求选择播放器。
2. 单一真实播放会话自动识别；切换到无会话App时旧暂停B站不会接管。
3. 多会话冲突和已销毁来源不执行媒体动作。
4. 已启动暂停定时到期只作用于原目标，当前播放识别可继续变化。
5. 无媒体控制能力仍可以实际开启黑幕、定时撤幕。
