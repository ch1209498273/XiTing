# v5.2 播放能力契约

| 能力 | 开放条件 | 不满足时 |
| --- | --- | --- |
| 黑幕与返回 | 悬浮权限有效、服务可启动 | 普通界面提供权限帮助，不暴露技术异常 |
| 来源 | 唯一PLAYING，或实际媒体音频活动加系统路由到有效会话 | 无会话不猜；路由补充信号只显示可能来自 |
| 播放/暂停 | 可靠状态且声明对应动作 | 隐藏无效控件，不向其他App发全局切换键 |
| 定时暂停 | 原会话有效、状态PLAYING/PAUSED/BUFFERING/CONNECTING且声明PAUSE | 不受理；受理后失效不改控新来源 |
| 进度跳转 | 可靠状态、有效时长且声明SEEK_TO | 隐藏跳转按钮 |
| 片尾定时 | 同一内容身份、有效时长/进度/速率 | 禁用片尾定时，不靠长度猜换集 |

到期只有明确PAUSED可称原本已暂停；PLAYING/BUFFERING/CONNECTING可请求PAUSE；STOPPED/NONE/ERROR及未知状态为UNAVAILABLE。请求后有限观察原会话，无响应为UNCONFIRMED，不把受理当声音停止。

媒体状态由播放器提供，不能当逐应用硬件音频证明。真机声音连续/停止需用户确认。兼容性结果绑定设备、App版本及内容类型。
