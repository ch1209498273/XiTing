# 息屏听剧 XiTing

给 OPPO / ColorOS（也适配其他国产安卓）用的「息屏听剧」助手——补上小米"视频工具箱"里那个功能的替代品。

> 看剧看到一半想闭眼听？想省电？想防误触？点一下悬浮球，整块屏幕（含状态栏、导航栏、手势条）**物理背光关闭**，视频App照常出声。

## 功能

### ① 黑屏遮罩（悬浮球）
- 在**任意视频App**（YouTube / 爱奇艺 / 腾讯视频 / 优酷 / B站 / 抖音……）播放时，点一下「息屏」悬浮球
- 整块屏幕**真·背光关闭**：通过焦点窗口携带 `BRIGHTNESS_OVERRIDE_OFF`，系统直接关掉背光——不是调暗，是和息屏一样黑、一样省电
- 所有触摸被屏蔽（口袋里不误触）；**双击任意位置**恢复画面
- 系统栏通过 `WindowInsetsController` 主动隐藏（从屏幕上边缘下滑可临时唤出）
- 需开启④无障碍服务（本App的无障碍**不读取任何屏幕内容**，仅用于黑幕窗口层级，可在系统设置里核验 `canRetrieveWindowContent=false`）

### ② 真息屏续播（推荐，最省电）
- 看剧时**直接按电源键**熄屏 → 助手检测到熄屏 → 1~3秒内注入"播放"媒体键（`AudioManager.dispatchMediaKeyEvent`）→ 视频App的MediaSession收到后**在真息屏状态下恢复出声**
- 这是 Tasker/MacroDroid 社区验证过的公开技巧；是否生效取决于各视频App对媒体键的响应
- 自带**片尾保活**：息屏后3分钟内若声音再断（视频播完被掐断等），自动再注入播放键（最多5次）
- 防误触发：只有"熄屏前4秒内确实在出声"才会注入；亮屏即取消所有待执行动作

### 其他
- **下拉快捷磁贴**：一键黑屏/恢复（助手未运行会自动拉起）
- **悬浮球位置记忆**、**开机自启**、通知栏快捷控制
- **完全离线**：不申请网络权限，不收集、不上传任何数据

## 安装后设置（ColorOS）

1. 打开App，按提示完成：悬浮窗权限 → 电池后台加白 → 通知权限 → **无障碍服务**
2. ColorOS三件套（防杀后台）：设置 → 电池 → 息屏听剧 → 允许后台运行；最近任务下拉卡片**加锁**；设置 → 应用 → 自启动 → 允许
3. 启动悬浮球，去任意视频App点它

## 原理说明与边界

小米的"息屏听剧"是系统级功能，第三方App无法复刻"真息屏后强制媒体进程不挂起"。本App用两条公开API路径逼近同等体验：

- **焦点窗口背光覆盖**（`WindowManager.LayoutParams.screenBrightness`）：Android只从"有焦点的全屏不透明窗口"读取亮度覆盖，黑幕因此能让系统**物理关闭背光**
- **媒体键注入**（`AudioManager.dispatchMediaKeyEvent`）：向系统派发标准媒体键，由当前MediaSession的持有者（视频App）自行决定是否恢复播放

限制：黑幕期间请勿按电源键后再期待遮罩保留（遮罩会自动撤除，属正常设计）；个别视频App不响应媒体键时，真息屏续播不生效，请改用黑幕模式或App自带的后台播放开关。

## 构建

```bash
git clone https://github.com/ch1209498273/XiTing.git
cd XiTing
gradle assembleDebug   # 或用 Android Studio 打开
```

要求：JDK 17+、Android SDK 36（AGP 8.13 / Kotlin 2.2）。
