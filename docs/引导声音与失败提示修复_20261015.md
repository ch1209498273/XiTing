# 引导声音与失败提示修复（2026-10-15）

## 已复现问题

手机v5.1.3无外部视频播放时，点击引导仍显示黑幕，但本应用UID10531没有started音轨。到期问声音是否正常，点“否”直接显示权限/媒体会话/暂停能力等技术诊断表。引导依赖外部视频返回本应用后继续播放，没有内置测试声音，也缺少对“没有声音”的友好恢复路径。

## 修复范围

- 内置离线中英文测试语音，无需其他播放器、网络、系统TTS引擎或通知使用权。中文使用中文样例，其他界面语言使用英语样例；界面说明与帮助保持8种语言。
- 进入黑幕前检查悬浮权限、已有黑幕/定时、媒体音量、其他正在播放的音频。静音时先显示音量/耳机帮助，不显示无声黑幕。不会擅自提高音量或暂停其他应用。
- 本地音频成功启动后显示黑幕；语音自然结束后返回。提前退出、焦点丢失、服务退出等路径释放播放器与焦点；旧回调按generation及实例过滤，15秒watchdog按失败处理。
- “没声音”和“没返回”只显示可操作的帮助，不自动跳技术诊断/错误详情。引导黑幕隐藏播放器与定时控件。
- 样例仅用于基础黑幕体验，不计入听剧时长/成长，也不据此宣称第三方播放器兼容。完成需用户明确确认声音及画面。

## 样例来源

Windows本地SAPI，Microsoft Huihui / Zira Desktop，未调用云服务。中文文稿：这是息屏听剧的测试声音。画面变黑，声音继续。稍后会自动恢复画面。英文文稿：This is a test sound. The screen goes dark while the sound continues. The picture will return shortly.

WAV：22.05kHz单声道16bit；中文8.550秒、RMS2031.8，英语7.983秒、RMS2967.3。APK中以未压缩raw资源存储供MediaPlayer本地读取。
