# 通用听剧找回交互稿

A阶段：无平台白名单，任何提供系统媒体信息或HTTP(S)分享链接的App均可参与。

首页：保留启动/停止主卡与三个页签；增加一行“最近听过 ›”，不挤占主按钮。

最近听过：顶部“保存链接”“管理与清理”；按时间显示内容标题、来源App和时间，点击进入详情；空态说明可分享或粘贴保存。列表分页50条。

详情：返回动作在最上方；仅App信息时写“打开来源App”，有链接写“打开原内容”；随后显示已知位置、设置定时起点和标记。底部“记一句”“关联链接”“保留这条”“删除”。无进度不画进度条。

保存预览：收到的标题（可编辑）→一个或多个HTTP(S)链接（多条必须选）→保存/取消；粘贴只在用户点击后读取。取消不写库。默认不猜来源App。

清理：默认90天，可选30/180/永久；预览到期普通记录数量再删除。手动标记/备注/主动保存/保留保护。清空全部单独确认。

黑幕：默认没有标记入口。设置打开“黑幕显示标记入口”后，唤醒面板才显示“记住这里”，点击短提示，不弹键盘。返回播放器保持主动作。

睡前：只在成功受理定时后记起点，不自动永久保护，不称检测入睡，不显示“已听完”。

视觉：复用当前浅色/深色、绿色主操作、卡片与字号；内容页使用滚动布局，主操作48dp以上，兼容大字。最终实际截图与点击UAT另行留证。
