## 它能做什么

### ① 黑幕遮罩（核心功能）

点悬浮球（或通知栏按钮 / 快捷磁贴）即可切换：

- 整块屏幕被**纯黑遮罩**盖住，并把窗口亮度设为最低；这不等同于系统真正关屏，也不保证所有机型硬件关闭背光
- 所有触摸被屏蔽，放口袋里也不误触
- 视频 App 认为自己在正常前台播放，**声音继续**

**两段式解锁**（防误触）：

1. 黑幕状态下轻点屏幕 → 解除锁定，背光恢复到你的亮度，浮现「点击返回视频」按钮
2. 点按钮 → 返回视频；**5 秒无操作自动重新锁定**

### ② 黑幕内的媒体控制（可选开启）

黑幕唤醒后可切集与进度：**快退30秒 / 上一集 / 播放暂停 / 快进30秒 / 下一集**。
因为黑幕挡住了通知栏，这里是媒体键唯一可达的位置。默认关闭（防误触），在「设置」中开启。

- ±30 秒只在视频 App 的媒体会话声明支持 seek 时才出现（`ACTION_SEEK_TO` 按应用探测），
  快进退到片头片尾自动停住
- **剧名/集数**：解锁瞬间显示正在播的内容（**两行**显示，超长自动省略；数据来自
  MediaSession metadata，只在你主动唤醒时可见，零打扰）。±30 秒与剧名依赖可选的
  「通知使用权」——未授权时二者隐藏（设置页开关下方有提示），切集/播放暂停照常可用

### ③ 暗色夜钟与电量显示（可选）

开启后黑幕中央显示极暗的时间与电量（`0x30FFFFFF`，几乎不发光），重锁后保持最暗背光持续可见。
针对 OLED 防烧屏：显示内容每 45 秒**微移 ±2px**（不可感知），让像素轮换休息。

### ④ 智能联动

- **来电自动退出黑幕**——不会漏接电话；通话期间不注入任何自动动作
- **耳机拔出 / 蓝牙断连自动撤幕**——返回视频界面，看到已暂停的剧
- **按电源键熄屏时自动撤掉黑幕**——唤醒后直接回到视频画面

### ⑤ 睡眠定时器

- **结束动作可选**：默认撤幕返回视频，也可请求暂停并保留黑幕；支持 N 分钟后执行，支持 15 / 30 / 60 分钟预设与**自定义 1–600 分钟**
- **「听完这集」**：读取当前视频的 MediaSession 播放位置与总时长，推算片尾时刻，到点执行所选结束动作

### ⑥ 电能精灵（养成）

听剧时长积累**成长值**（每满 1 分钟 1 点能量，含跨会话余数累积），精灵五形态进化：

`电火花 → 电球 → 雷云精灵 → 风暴之灵 → 雷霆之王`

- 左侧常驻能量条，点击即充能并收入成长值
- 已解锁形态可**切换为悬浮球头像**
- 精灵图鉴画廊：查看所有形态并换肤
- 成就系统记录听剧里程碑；连续天数（streak）统计
- 成就弹窗里点某条 → 精灵身上对应格徽章脉冲高亮
- 满级后继续储备，不再浪费

### ⑦ 省电估算（本机样本与模型）

统计页展示累计省电估算（mAh），并区分本机样本估算与通用模型估算。

**采样方式**：读取电池的**剩余电荷计数器**（`BATTERY_PROPERTY_CHARGE_COUNTER`，单位 µAh），
用正常亮屏片段与黑幕会话的电荷差、时长分别估算整机平均电流，再折算为 mAh。
黑幕会话开始和结束时读取，亮屏侧在服务运行时周期采集，无需专门执行测试。

有效性过滤包括：插电时不采集、计数器不降或不可用时丢弃、短于 2 分钟的片段丢弃、
平均电流异常的片段丢弃、熄屏锁屏不计作亮屏样本。计数器支持情况和精度因设备而异。

样本不足或无法形成有效对比时使用通用模型；界面的**样本数量等级**只表示两侧采样积累量，
不是统计置信度，也不代表测量精度。正常亮屏与黑幕期间的播放器、网络、负载和温度可能不同，
因此本机样本估算也**不是严格同场景对照的节电因果证明**，不能推广到所有机型。

### ⑧ 本周小结

统计页新增卡片，给的是**有对比**的信息，而不只是三个绝对值：

```
本周听了 12 小时
比上周多了 24%（3 小时）
听了 5 天 · 8 次息屏
本周省电约 340 mAh
精灵 电火花 → 雷云精灵（+720 成长值）
```

按「本周一 00:00」至当前时刻统计，而非滚动「最近 7 天」。

### ⑨ 分享海报

统计页可生成分享图：带上**你自己的精灵**（当前形态 + 当前配色）、
本周数据与省电量，背景跟随皮肤色相。**发送前可预览**，预览顶部可一键切换
**3:4（朋友圈/微博）与 1:1（小红书）**两种版式（2026-10-11 新增 1:1），
可选择分享或保存到相册。

两种版式的纵向坐标由 `PosterLayout`（纯函数 + 单测）统一推演：
放不下时先收缩精灵，页脚永不裁边；3:4 的每个坐标与旧版逐像素一致（回归锚测试钉死）。

### ⑩ 多语言

8 种界面语言，覆盖所有界面文案，在「设置 → 语言」切换，**无需重启**。

翻译维护由 `tools/i18n.py` 辅助：新增文案后跑一次 `sync` 自动同步到所有语言；
漏翻的条目标成 `⟨TODO⟨中文原文⟩⟩` 并由 `check` 报出，而不是沉默地混入中文。

### ⑪ 数据备份

- Android 10+ 在主界面进入后台时尝试**自动备份**到「下载 / XiTing」公共目录；可在备份管理关闭。本地为空时跳过，内容变化时新增时间戳文件并保留历史，卸载不会删除公共备份
- 手动导出到系统文件选择器指定的位置 / 从所选备份文件恢复；文件提供方可能是云盘
- 重装后仅在本地无成长值且发现本机标识匹配的备份时提示恢复；能否发现受系统文件访问规则影响
- v4备份内容：成长值、保留会话明细、**精灵形态、配色、已解锁皮肤、成就记录**，待收能量与原到期时间、分钟余数、长期聚合、会话结果摘要及部分用户设置。运行状态、权限授予和媒体目标不复制；旧v1–v3格式保持兼容
- 备份还含 `ANDROID_ID`、备份时间和分享日期；合法完整v3聚合直接恢复，旧备份缺失聚合时仍从明细重建，不能找回旧备份未保存的历史
- 恢复前需停止助手，并保存应用私有回退快照；备份管理可撤销上次恢复。历史文件仅在用户明确确认后删除；系统文件访问限制可能使部分公共备份不可见或不可删

### 候选升级：诊断、历史与常用设置

- 首页提供服务与权限状态，帮助中提供必要的排查说明；播放器响应取决于第三方App
- 首次演示后分别确认声音与返回画面，失败进入诊断；自动检查不等于真人操作验证
- 历史管理支持日期筛选和CSV导出；删除单条前确认，保留成长和已解锁项。旧月份明细不完整、无法准确重算时阻止删除
- 常用听剧方案只保存时长与结束动作，使用时重新选择并验证播放器；支持浅色、深色、跟随系统及首页次级入口排序
- 服务中断或重启后保留提示，原黑幕及定时不自动重放；用户明确停止助手后不会因设备重启自动启动
- 系统云备份在配置中排除应用数据；Android 12+ 保留系统换机迁移，具体行为取决于系统实现

### ⑫ 桌面小组件 ×3 尺寸

精灵形象、听剧数据与一键息屏，常驻桌面。

更新靠**事件推送**（会话结束、开关切换、退出等），而不是 30 分钟轮询——
轮询意味着系统每天要唤醒进程 48 次去刷一个大多数时候没变化的小部件。

1. 打开「息屏听剧」→ 首次进入会逐项引导权限 → 点**启动悬浮球**

### 运行单元测试

```bash
powershell -ExecutionPolicy Bypass -File tools\run_tests.ps1
```

脚本会把源码镜像到临时 ASCII 路径再跑，跑完汇总结果并清理现场。

**为什么要绕这一圈**：本项目路径含中文，Gradle 执行单测时 fork 的测试进程
通过 `@argfile` 接收 classpath，而 JVM 解析 `@argfile` 发生在
`-Dfile.encoding` 等参数生效之前，中文路径被解错，于是**所有测试类都报
ClassNotFoundException**。已用对照实验确认：同一份代码复制到纯 ASCII 路径后
全部测试绿。`assembleDebug` / `assembleRelease` 不受影响，只有单测任务受影响。

覆盖范围（当前 **232** 个）：

- **日期与连续天数**：同一天去重、时区日界线、DST 干扰、周一边界
  （`StreaksTest`）——「持之以恒」成就与皮肤解锁都依赖它
- **省电实测的算式**：短样本丢弃、计数器上升丢弃、异常高速率丢弃、
  **黑屏比亮屏更耗电时返回 null 而不是负数**（「省了 -300 mAh」是误导）（`MeasMathTest`）
- **周报**：本周/上周分段、周边界、成长值推导（`WeekReportTest`）
- **备份导入**：会话限量、会掉队的畸形条目、**v1 老备份缺新字段时不得清空现有设置**、
  非字符串 id 不得写入（`BackupImportTest` / `BackupProgressTest`）
- 存档与能量的逐条容错、成长值溢出饱和、成就残留 id
- 把 26 个持久化键名钉死（`PrefsKeysTest`）——改键名等于全体用户丢失该设置，
  必须有人会注意到
- 精灵光晕几何（`PetGlowTest`）、配色派生（`PetPaletteTest`）、
  成就徽章（`BadgesTest`）
- 海报版式：3:4 回归锚（与旧手写坐标逐像素一致）+ 两比例×四行的不变量 +
  弹性收缩方向（`PosterLayoutTest`）
- ±30 秒的目标位置换算：越片尾夹片尾、越片头夹 0、时长缺失只保下限（`SeekMathTest`）

## 原理与局限（必读）

小米的「息屏听剧」是**系统级功能**：靠系统权限在息屏后阻止系统挂起媒体进程，所以能真正关屏。
普通第三方 App 拿不到这个权限，**无法让「别人的 App」在真息屏（屏幕完全关闭）后继续出声**。

本项目使用**黑色遮罩 + 降低窗口亮度**，系统仍保持亮屏；它不等同于系统关屏：

| | 真息屏（小米系统功能） | 本 App 黑幕 |
|---|---|---|
| 屏幕 | 系统关闭屏幕 | 系统保持亮屏，黑色覆盖并降低窗口亮度；不保证背光关闭 |
| 显示耗电 | 取决于设备和系统 | OLED 黑色像素通常发光较少；LCD 仍可能有背光，效果因机型而异 |
| 解码耗电 | 取决于播放器实现 | 原播放器仍可能继续视频解码，无法给出统一节电比例 |
| 适用范围 | 取决于系统和播放器 | 取决于悬浮窗限制、后台策略及播放器行为 |

> 黑幕不会把其他应用变为纯音频解码。系统亮屏、前台服务与播放器仍会耗电，实际节电效果需在具体设备和使用条件下判断。

**因此本 App 没有、也不打算提供以下功能**（早期版本曾经有过，现已移除）：

- ❌ **真息屏续播**（熄屏后自动注入媒体键恢复播放）——该方案在真息屏下不稳定且无法保证，已整体移除
- ❌ **无障碍服务全屏黑幕**——黑幕走悬浮窗层；另有可选的实验性无障碍字幕服务，会读取文本节点，不负责黑幕显示或广告跳过
- ❌ **广告自动跳过**——已彻底移除

## 常见问题

- **点悬浮球没反应？** 悬浮窗权限没给。
- **黑屏一会儿声音停了？** ColorOS 把后台杀了，按上面「电池 / 加锁 / 自启动」设置。
- **黑屏状态下没声音？** 点一下屏幕解除锁定，看视频 App 是否已暂停；部分 App 在后台会自动暂停。
- **状态栏/手势条还露着？** 应用已通过 `WindowInsetsController` 主动隐藏系统栏并申请沉浸式。若个别 ROM 上仍有残留，从屏幕上边缘下滑可临时唤出、松手自动隐藏。
- **黑屏期间来微信/接电话？** 通知照常响；来电会自动撤掉黑幕。屏幕黑着时无法直接操作，双击/轻点恢复画面即可。
- **想切下一集但通知栏被挡住？** 在「设置」里开启黑幕内媒体控制，唤醒状态下有上一集/播放暂停/下一集。
- **定时器没反应？** 定时器到点会执行所选结束动作；请求暂停取决于播放器支持；若期间接了来电，黑幕已自动撤除，定时仍会按时提示。
- **「省电估算」一直显示样本不足？** 需不插电、设备计数器可用，且亮屏与黑幕两侧都有足够有效样本。部分机型可能始终使用通用模型，样本增多也不保证精度。
- **切了语言要重启吗？** 不用。「设置 → 语言」选完立即生效。
- **分享图能自己选精灵吗？** 不能。分享图用的是**当前**形态与当前配色，想换先在图鉴里换。

## GitHub 调研结论

### 分享海报（2026-10）

在 GitHub 上按 stars 搜了一圈分享卡的实现，结果有点反直觉：

- 分享卡生态**几乎全在 Web 端**（`setkyar/laravel-social-share-cards`、`vercel/satori`、
  Next.js 的 og-image 方案），语言分布是压倒性的 PHP/TypeScript
- **「Android 原生画布生成分享图」搜不到任何有 stars 的成熟库**

这不是生态缺失而是场景差异：原生 App 要分享时图往往已经在本地（截图、订单、账单），
直接分享现成位图即可；而 Web 需要把 URL 渲染成图才能分享。
**「本地数据 → 生成图 → 分享」在移动端属于本地自绘，没有现成方案可抄。**

业界主流的版式描述方式是 **HTML/CSS → 渲染成图**（`vercel/satori` 的定位是
*convert HTML and CSS to SVG*）。这个思路值得借鉴，**但 satori 是 Node 库
（依赖 wasm 与字体），搬不到 Android 上**。因此本项目的做法是手写 Canvas，
但把版式常量集中在一处、按画布高度推演排布，避免改一处就压到另一处。

详细分析见 [分享功能升级方案](docs/分享功能升级方案.md)。

### 息屏听剧（2026-09）

- [xiaoyudianbaba/ScreenOffDrama](https://github.com/xiaoyudianbaba/ScreenOffDrama)：与本工程方案几乎一致（纯黑悬浮窗 + mediaPlayback 前台服务），差异点在于它用无障碍服务做 YouTube 广告自动跳过。
- [Blackr: OLED Screen Off](https://play.google.com/store/apps/details?id=com.neximolabs.blackr)（百万安装）：同为纯黑遮罩方案，佐证这是免 root 场景的行业标准做法。
- V2EX 讨论（MIUI 14 无息屏听剧）：社区提到酷安「熄屏挂机」工具用 Shizuku(shell)/root 实现；本项目坚持免 root 路线。
