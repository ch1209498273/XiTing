# v6.0.0：听过的内容，方便找回

本版继续专注辅助其他视频 App 听剧，新增本机内容记录与找回能力，不限制播放平台。

## 新增功能

- **最近听过**：黑幕期间记录系统能够可靠识别的内容及可用位置，方便之后查看。
- **保存原内容链接**：从其他 App 的系统分享中选择息屏听剧，或主动粘贴链接；确认预览后保存。
- **记住这里**：可在设置中开启黑幕标记入口，记录当时的位置，之后添加备注。入口默认关闭。
- **睡前定时起点**：记录设置定时时的位置，并区分取消、替换、已结束及播放器确认暂停等结果。
- **保留与清理**：普通记录默认保留 90 天，可改为 30 天、180 天或永久。主动保存、手动标记、备注及手动保留的内容不会自动清理；可单条删除、预览到期清理或确认清空。
- **备份升级**：新版备份包含内容记录，读取旧备份时保留本机已有内容库。

## 使用体验

保留熟悉的首页、统计和设置。当前来源尽量显示应用名与可用内容信息；无法识别时如实提示。黑幕定时入口与标记入口分别控制，默认隐藏，减少误触。内容清理不改变累计时长、成长和成就。

## 能力边界

记录仅存本机，应用无 INTERNET 权限。主动导出、分享及系统迁移的数据仍可能离开本机，见[隐私政策](../../PRIVACY.md)。

标题、位置及暂停能力取决于播放器向系统提供的信息；缺少可靠身份时不按相同标题自动合并。内容链接可能先打开网页，再由网页打开播放器；不保证恢复到记录的位置。无链接时只能打开来源 App。
