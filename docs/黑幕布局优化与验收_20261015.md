# v5.1.6 黑幕操作面板优化

## 交付状态

布局开发、模拟器验收及手机重连后的真机验收已完成，候选版本为 **5.1.6/code95**。最终归档候选已覆盖安装到 OPPO PME110/API36，包版本核验一致，未清除原数据；用户确认抖音黑幕“显示正常，声音连续”。未发布线上渠道。

安装包：`docs/升级候选/XiTing-v5.1.6-code95.apk`。最终 SHA-256、版本及验收状态见 `docs/uat-black-layout-20261015/acceptance.json`。

## 已实现

- 黑幕唤醒后显示一个紧凑的深色底部面板，竖屏最大宽度420dp，横屏最大宽度680dp；根据实际窗口宽高切换为两列。
- 应用名使用次要文字，内容标题使用独立主标题。竖屏最多两行，横屏最多一行；不可靠来源保持“可能来自”的限定，不展示历史标题。
- 播放/暂停为主要控制，其余控制按能力显示。无法使用的单个按钮及整排无效控制隐藏；可选播控开关仍有效。
- 合并定时状态与设置入口。未启用时显示“未开启”；启用后显示倒计时与执行动作，并显示延长15分钟和取消。
- 返回入口改为“返回播放器”，去除锁头图标和大面积绿色填充；内置体验单独显示“结束体验”。
- 面板预留系统栏、导航及刘海区域。普通字体下不需要滚动，大字体或高度不足时可滚动到完整操作按钮。
- 唤醒后的顶部提示改为“轻点空白处继续黑屏”。重锁保留纯黑与已有可选时钟行为。
- 修复审查发现的重复唤醒动画问题：清理旧动画结束动作，恢复引导标题透明度，避免再次唤醒后提示或按钮消失。
- 八种语言均已更新；未修改播放来源策略、媒体控制目标绑定或音频播放链路。
