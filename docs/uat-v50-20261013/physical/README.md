## UAT50-PHY-01：哔哩哔哩定时配置目标不可见（P1待解决）

复现：哔哩哔哩前台正在播放，媒体会话报告PLAYING并声明PAUSE/SEEK能力；切换到XiTing打开定时面板，播放器列表未包含哔哩哔哩，只暴露另一个媒体应用。1分钟和“请求暂停，保持黑幕”仅填入面板，**没有确认启动**，没有向其他播放器发送暂停，随后取消。

当前结论：黑幕续播通过；本次运行场景的哔哩哔哩定时暂停未完成，不能因模拟器合成MediaSession测试通过而标记真实播放器通过。会话在前后台切换后的可见性与服务选取需进一步定位，不能推广为所有哔哩哔哩内容永久不支持。

下一修复方向：评估在用户明确选择播放器时保留原会话控制器，或在播放器前台通过悬浮入口配置定时；仍须原目标绑定、失效检测与暂停确认。禁止用全局PLAY_PAUSE或默认另一个播放器代替目标。不在本次验收中临时替换手机正式包的媒体控制规则。
