# v6.1.0 更新说明

> 本版从 v6.0.0（versionCode 99）之后累计 12 个提交，versionCode 递增 1。
> 一句话：**把"权限到底开没开对"这件事从用户自己去猜，改成 App 自己说清楚、并给一键可点的路。**

## 新增

- **首页「服务与权限」新增第四行「通知使用权」**。以前那里只有悬浮窗权限、电池后台加白、通知权限三行，而报错文案要的是「通知使用权」——两者名字只差一个字、方向相反（一个是本 App 能否弹通知，一个是能否读取别的 App 正在放什么）。现在第四行状态直接读真实授权结果，点一下跳系统开关页。
- **睡前定时弹窗内给出「去授权」出口**。未授权时提示不再和"没有会话"混成同一句话，改说「未授权读取媒体控制 · 可用黑幕和定时返回」，下面出现「去授权」按钮，直达系统通知使用权页。改造前 App 内**没有任何一条路**能打开那个开关。
- **设置页「数据」组新增「诊断与自检」入口**。这个面板早就写好了（逐条列出悬浮窗、通知使用权、通知、电池豁免、媒体会话、播放中、暂停/跳转/切集声明、助手服务、黑幕状态），但生产界面一直没有入口，只在测试代码里被调用。现在它会显示「通知使用权: 否」并把主按钮变成「开启通知使用权」。
- **定时弹窗改实时重读**。会话与权限原本只在打开弹窗那一刻读一次，授权完回来仍是灰的、必须关掉重开。现在弹窗窗口重新获得焦点即自动刷新，改时长下拉作为兜底刷新点。

## 修复与调整

- 黑幕切集键改为**常驻显示**：未声明 `ACTION_SKIP_TO_*` 的播放器（不少短视频 App 只处理媒体键、不写能力位）以前会让按钮凭空消失；现在先注入媒体键试一次，用内容签名判定有没有生效，没生效才判死转灰，判死只对当前这条内容负责、换内容或超时即复活。
- 防误触锁定改为可配置开关（双击解锁、长按返回、电源键锁屏后保留黑幕），默认关，升级用户不改变肌肉记忆。
- 「最近听过」放宽为**有标题就记录**：v6.0.0 实际只记录愿意提供 media id 的播放器，多数国产播放器不给就不记；现在缺 media id 退回标题键，历史条目仍按包名区分不因同名合并；连标题都不给的播放器会留一条「未识别内容」的来源条目。
- 首屏记录改 10 条并修正大库首屏口径；修复每行播放器图标复用同一 Drawable 的问题。
- 修复英文界面电池状态位歧义：未加白时显示 "Exempt"，读起来像已加白，改为 "Not exempted"。中文与其他语言包遵循的是同一套约定（开态过去分词、关态动词原形），未改。

## 用户会看到什么变化

- 首页权限区多一行，能一眼看出「通知使用权」到底开没开。
- 定时弹窗里那个灰色选项不再是死胡同：没授权会告诉你缺的是哪个开关，并按一下就带你去。
- 授权回来不用关掉重开弹窗。
- 报障形态「提示要开通知权限，我开了还是不行，于是挨个换浏览器/腾讯/优酷/爱奇艺」应当不再出现。

## 本版未验与已知边界

1. **真机未覆盖**。报障用户用的是 ColorOS 机型，本轮全部证据来自模拟器。
2. **会话刷新的后半条未在模拟器证明**：「新播放器出现 → 单选变亮」。模拟器造不出"后台仍在 PLAYING 的会话"（测试夹具在 `onStop` 里故意自动暂停，Android 15 又禁止后台起音频）。真机补验方法：播放器开「听视频/后台播放」让声音继续 → 打开睡前定时 → 从别处切回来或按一下时长下拉。
3. **弹窗内会话判据未改**：只认"正在播放"或"已被选为黑幕目标的暂停会话"，暂停过的历史会话不提升。因此若播放器切出时自己暂停了，仍需在黑幕内设置定时或开启播放器后台播放——这是既有设计，不是本版回归。
4. **自愈依赖窗口焦点回调**：若个别 ROM 返回时不触发焦点变化，兜底是改时长下拉，再兜底是关掉重开（行为与改造前一致）。
5. 抖音等短视频 App 是否响应注入的媒体键，仍由探针在真机自行给答案：判死即转灰并出说明，生效即键常亮。
