# v4.3.1 成就点击修复

用户反馈：统计 → 成就，点击未解锁徽章会退出成就子页（返回统计页，并非 App 崩溃）。

根因：旧代码在判断是否解锁前先 dismiss 成就列表；未解锁分支继续跳至统计页并触发精灵徽章高亮。v4.3.0 的原生验证覆盖了静态未解锁渲染和已解锁详情函数，但漏掉真实未解锁行点击，这个交付遗漏需要承担。

修复：未解锁行先判断，保持成就列表打开，通过 Toast 显示对应条件；已解锁行继续关闭列表并打开动画详情。未改门槛或用户数据。

验证：
- RED：真实列表第一行点击，旧逻辑失败 `Locked achievement 0 closed the achievement list`。
- GREEN：逐个点击四枚未解锁成就，列表持续显示、Activity 存活、成就未增加、成长值和图标选择不变。
- 逐个点击四枚已解锁成就，打开含重播按钮的详情，实际点击重播并返回，解锁集合保持不变。合成状态仅在隔离模拟器写入，并在 finally 恢复。
- 13 项原生模拟器检查通过；134 项 JVM 测试通过，失败/错误/跳过均为 0；Lint `No issues found`。
- 正式包签名验证通过，证书与此前发布一致；4.3.1 / code85。
- APK SHA256：2D768DB2CB8703948CF995DEC3D1E7AE57DDAFEC95D24296C962927E1232D31E。
- 手机 adb install -r：Success；包管理器 4.3.1 / 85；MainActivity COLD 启动 Status: ok，进程存在。没有卸载或修改手机成就状态，未读取手机界面。
- 实际点击验证来自隔离模拟器，手机核实范围是覆盖安装和启动，不能替代用户在实体手机上的点击结果。
