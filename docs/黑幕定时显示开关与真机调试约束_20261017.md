# 黑幕定时显示开关与真机调试约束

## 用户问题及改动

- 用户反馈调试反复开启手机自动旋转，干扰正常使用。工程与保存脚本搜索未发现写入旋转设置的实现，无法仅据代码断定历史开启来源。本轮新增项目AGENTS.md约束：真机调试不修改旋转或字体；旋转/字体矩阵只在模拟器执行；不能用“开启自动旋转”作为通用恢复步骤。
- 用户明确要求定时在黑幕中可选择显示，减少误触。新增设置“黑幕显示睡前定时”，新老用户未主动开启时默认关闭。
- 关闭后隐藏黑幕的定时入口、倒计时、延长和取消按钮。已打开的定时编辑器也会收起；返回播放器按钮保留。隐藏节点不能再打开定时编辑器。
- 已受理定时在后台继续执行，显示开关不取消、不重建定时，也不重挂黑幕或拆分听剧会话。首页定时入口仍保留。
- 偏好使用独立键black_timer_show，已加入备份白名单；从没有该键的旧版本升级时默认隐藏。恢复旧备份不会覆盖本机已经选择的显示偏好。八语言设置文案同步。
