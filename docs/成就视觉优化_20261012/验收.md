# 成就金色勋章与解锁动画候选验收

用户选择：先加强徽章视觉与解锁动画，采用统一金色勋章风格。本轮保留四项成就门槛、已解锁数据和成长规则。

## 已实现

- 四枚共享金色金属底盘、刻度边缘和浮雕高光；成就弹窗与精灵徽章列使用同一绘制源。
- 新解锁批量展示，替代仅显示前两条的 Toast；后台/黑幕期间保存待展示集合，返回有焦点的界面后展示一次。
- 已解锁徽章可查看大图与重播；未解锁徽章仍为灰色轮廓，不会借预览写入解锁状态。
- 1.8秒弹入、光环和粒子动画：沙漏金沙、火焰火星、靶心圆环、皇冠星芒。
- 动画遵守系统关闭动画的设置；到时、失焦、隐藏或脱离窗口即移除重绘任务。点击重播不修改成就或成长。
- 修正共享Paint的halo透明度泄漏，金属底盘在动画中保持不透明。
