# 竞品深度分析：Black Screen (io.japp.blackscreen) v2.0.7

> 分析方式：真机拉取 APK（11MB，versionCode 97 = 迭代97版），aapt 解析清单/权限/593条资源名。
> 分析日期：2026-09-30

## 一、产品概况
- Play 商店工具类头部产品，订阅(monthly/yearly) + 买断(one_time/lifetime) + 免费试用 三轨收费
- Pro 墙：去广告 / 高级时钟样式 / 高级锁样式 / 防窥模式 / 媒体控制 / 优先支持
- 带 Firebase 统计 + 广告（AD_ID）+ Instagram 引流 + 交叉推广
- 权限：SYSTEM_ALERT_WINDOW / WAKE_LOCK / FGS / 通知 / BOOT / 生物识别 / BILLING / AD_ID / INTERNET

## 二、完整功能清单（按设置分组还原）

### quick_access 快捷入口
- 桌面快捷方式（add_home_screen_shortcut）
- 快捷磁贴 ✓（我们已有）+ 磁贴直黑模式（点击磁贴直接黑屏，而非打开悬浮球）
- 通知栏 显示/隐藏黑幕

### floating_button 悬浮球
- 悬浮球贴边吸附（snap_to_edge）
- 悬浮球长按动作可配置（long_press_action）
- 悬浮锁大小/样式可调
- 可隐藏悬浮球（用通知开关替代）

### wake_unlock 唤醒与解锁
- 解锁方式可配置：轻点直接解锁 / 点击次数（taps_to_wake）/ 跳过解锁屏
- 解锁认证（生物识别或设备PIN）
- 唤醒方式：点击唤醒次数

### what_appears 黑幕上显示什么
- 黑幕时钟：样式/颜色/大小/日期格式/24小时制
- 黑幕显示电量百分比（电池图标旁）
- 未读通知图标 ✓（我们 v2.15.0 已有）
- OLED 防烧屏（周期性移动屏幕内容）
- 防窥模式（Pro）

### display 显示
- 屏幕类型切换：OLED 纯黑 / LCD 压亮度
- 全屏模式

### system 系统
- 电池优化白名单 ✓
- 电池省电统计（区分 LCD/OLED 说明）✓ 我们有
- 总熄屏时长 / 最长会话 统计
- 应用内语言切换
- 口袋检测（放兜里防误触/防亮屏）

### 其他
- 生物识别保护设置入口
- 桌面快捷方式
- 评分引导/反馈/Instagram/交叉推广
