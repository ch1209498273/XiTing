# 五阶精灵升级：实现与验收

2026-10-11。基于 4.0.2 / versionCode 81 的本地候选构建，未发布新版。

## 已实现

| 等级 | 可辨识造型 | 专属交互与反馈 |
|---|---|---|
| Lv.1 电火花 | 小火种、尖顶 | 轻点点亮，火星上浮 |
| Lv.2 电球 | 圆团、小手、能量环 | 轻点弹跳；按住蓄力，松手回弹并释放波纹 |
| Lv.3 雷云精灵 | 云团、底部闪电 | 轻点释放闪电并抖动 |
| Lv.4 风暴之灵 | 云冠、旋流尾、前后风带 | 左右拨动旋转，风带与粒子增强 |
| Lv.5 雷霆之王 | 金冠、双翼、小脚 | 轻点回应；长按后松手展翼，星辉增强 |

采用共享原生 Canvas 渲染器，统计页、悬浮球和使用 PetView 生成的图鉴、组件、分享图保持同一套轮廓。小图与静态图减少粒子；悬浮球保留原有点击、拖动操作。统计页新增随等级变化的交互提示，八种语言资源齐全。

保留五阶 ID、成长阈值和已有皮肤数据。帮助和能量条独立命中，精灵手势不重复派发点击；竖向拖动与取消不触发精灵动作。隐藏、脱离窗口、滚出可见区及系统关闭动画时停止常驻动画调度，首次布局后启动。
