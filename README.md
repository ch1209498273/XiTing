# 息屏听剧（OPPO/ColorOS 通用版）

一个给 OPPO（ColorOS）手机用的「息屏听剧」小工具——补上小米"视频工具箱"里那个功能的替代品。

## 分发说明（v2.1.0起）

广告自动跳过功能已移除，计划独立成单独的应用发布；本App回归单一版本，专注黑幕遮罩与真息屏续播。构建：`gradle assembleDebug`。

## 它是什么

提供**两种听法**：

### ① 真息屏续播（v1.1新增，v1.2.x增强，推荐）
**先点「启动悬浮球」让服务保持运行**，然后看剧时**直接按电源键**熄屏 → 助手检测到熄屏 → 1~3秒内注入"播放"媒体键（`AudioManager.dispatchMediaKeyEvent`，公开API）→ 视频App的MediaSession收到后**在真息屏状态下恢复出声**。屏幕完全关闭，最省电。

已在Android 13模拟器上完成端到端UAT（真息屏→暂停→自动恢复出声全程logcat+dumpsys验证）。

- **YouTube专项（v1.3.0保活监控）**：YouTube（非Premium）允许"锁屏后按播放键恢复"，本App注入的媒体键走同一条MediaSession通道；但YouTube会在**片尾把后台播放掐断**（后台自动连播是Premium功能）。v1.3.0起息屏后启动**3分钟保活监控**（每8秒巡检）：声音再断就自动再注入PLAY救回（最多5次，片尾被掐后重播的是当前这一集）；彻底无声才发"未生效"提醒
- 判定时机：2秒轮询`isMusicActive`+播放回调双保险，取"熄屏前4秒内是否有声音"（v1.2.2修复：持续播放期间回调不再触发导致时间戳陈旧漏判）
- 防误触发：熄屏前4秒内没在出声就不注入（手动暂停后锁屏不会误恢复）
- 防重复派发：每轮注入前检查`isMusicActive`，已恢复就跳过（v1.2.3修复：PLAY_PAUSE可能把已恢复的播放又切暂停）
- 亮屏即取消：SCREEN_ON时取消所有待执行的续播/保活，不干扰正常操作
- 若最终无声，发提醒：该App不支持媒体键唤醒，改用方式②
- 通知栏可随时开关"真息屏续播"

### ② 黑屏遮罩（悬浮球）
在任意视频App播放时，点一下屏幕上的**「息屏」悬浮球**：

- 整块屏幕被**纯黑遮罩**盖住。开启④无障碍全屏黑幕后走`TYPE_ACCESSIBILITY_OVERLAY`层（系统栏之上），**状态栏、导航条、手势条全部盖黑**（已在模拟器上像素级验证：上/中/下三区RGB均为纯黑0,0,0）；不开无障碍则退回普通悬浮窗层（手势条可能露出）
- 所有触摸被屏蔽（口袋里也不误触）
- **真·背光关闭（v1.5.0核心）**：黑幕窗口为焦点+全屏不透明窗口，携带`screenBrightness=BRIGHTNESS_OVERRIDE_OFF`，系统据此**物理关闭背光**——黑幕期间与真息屏一样黑、显示功耗≈0，彻底解决ColorOS状态栏残影（v1.4.0的"改系统亮度压暗"方案已废弃，也无需"修改系统设置"权限）
- **主动隐藏系统栏（v1.6.0）**：ColorOS把状态栏/导航栏画在一切第三方窗口之上，z序盖不住；v1.6.0起黑幕作为焦点窗口通过`WindowInsetsController`主动申请隐藏系统栏（从屏幕上边缘滑入可临时唤出，松手自动隐藏）
- 视频App认为自己在正常前台播放，**声音继续**
- **双击黑屏任意位置**恢复画面（背光随即点亮）；黑屏状态下按电源键会自动撤掉遮罩
- 黑屏期间屏幕不可见属正常（背光已关），亮度键无效也是正常的；黑幕会吞掉所有触摸防误触

通知栏提供：息屏听剧 / 恢复画面、真息屏续播开关、退出助手。

### v1.7.0 新增优化

- **广告自动跳过引擎（v1.7.0引入，v1.8.0扩展范围，v1.9.0起仅full自用版）**：④无障碍开启时全天候工作——**与黑幕开不开无关**，正常亮屏看视频时照样生效。范围三档（主界面⑥切换）：关 / **主流视频App**（YouTube含精确按钮ID、爱奇艺、腾讯视频、优酷、芒果TV、B站、抖音、快手，文本匹配"跳过/跳过广告/Skip"）/ **全部App**（连各App的开屏广告"跳过"都点，误触风险自担）。注意：从v1.6.0及更早版本升级，或无障碍配置变更后，需把无障碍服务**关一次再开一次**才会生效
- **下拉快捷磁贴**：通知栏下拉 → 编辑磁贴 → 把"息屏听剧"加进来。点击即一键黑屏/恢复；助手没运行时会自动拉起
- **悬浮球位置记忆**：拖到哪下次就在哪（重启也记得）
- **开机自启**：重启手机后悬浮球自动出现（ColorOS需在 设置→应用→自启动 里放行）

### 各视频App自带的免费开关（零工具方案）
- **YouTube**：官方后台播放需Premium；免费兜底=Chrome打开youtube.com→切"桌面版网站"→播放后锁屏→在通知栏/锁屏按播放键恢复（Chrome设置→网站设置→"后台视频播放"保持开启）
- **B站**：设置 → 播放设置 → 后台播放（免费，锁屏也继续）
- **爱奇艺**：全屏 → 右上角三点 → 音频（后台需VIP）
- **腾讯视频**：三点 → 音频播放（需VIP）

### 原理与局限（必读）

小米的"息屏听剧"是**系统级功能**：靠系统权限在息屏后阻止系统挂起媒体进程，所以能真正关屏。普通第三方App拿不到这个权限，无法让"别人的App"在真息屏后继续出声。

本项目用的是业界通行的替代方案——**黑色遮罩**：

| | 真息屏（小米系统功能） | 本App黑幕（v1.5.0背光关闭） |
|---|---|---|
| 屏幕 | 完全关闭 | 系统保持"亮屏"状态，**背光物理关闭** |
| 显示耗电 | 最低 | ≈最低（背光已关） |
| 解码耗电 | 只有音频解码 | 视频解码继续（耗电约为看视频的 40-60%） |
| 适用范围 | 仅自家视频App | 任意视频App |

> 近几年的 OPPO Reno / Find 系列都是 OLED 屏，黑屏遮罩的显示耗电接近真息屏；主要耗电在视频解码本身，这个只有让视频App自己支持"纯音频模式"才能省掉。

## ColorOS 权限设置（装完必做）

1. **悬浮窗**：首次打开App点按钮跳转；或 设置 → 应用 → 息屏听剧 → 悬浮窗 → 允许
2. **电池**：App内点按钮申请"忽略电池优化"；再到 设置 → 电池 → 更多设置 → 找到"息屏听剧" → 允许后台运行
3. **后台加锁**：最近任务界面，下拉"息屏听剧"卡片 → 加锁 🔒（防止被一键清理）
4. **自启动**（如果悬浮球总消失）：设置 → 应用 → 息屏听剧 → 自启动 → 允许

## 使用流程

1. 打开"息屏听剧"App → 四项权限/开关都 ✓（悬浮窗、电池、通知、无障碍全屏黑幕）→ 点**启动悬浮球**
2. 切到任意视频App开始播放
3. **听法A（真息屏，推荐）**：直接按电源键熄屏 → 1~3秒后声音自动回来
   **听法B（黑屏遮罩）**：点右侧**「息屏」悬浮球** → 黑屏，开始听
4. 想看画面：真息屏就正常亮屏解锁；遮罩模式**双击黑屏任意位置**
5. 彻底退出：通知栏 → 退出助手

## 常见问题

- **点悬浮球没反应？** 悬浮窗权限没给。
- **黑屏一会儿声音停了？** ColorOS把后台杀了，按上面"电池/加锁/自启动"三步设置。
- **按电源键后声音没回来？** 该视频App不响应媒体键唤醒（少数App如此），改用悬浮球黑屏遮罩，或开该App自带的"后台播放/音频模式"。
- **黑屏期间来微信？** 通知照常响，但屏幕黑着无法操作；双击恢复画面即可。

## GitHub 调研结论（2026-09）

- [xiaoyudianbaba/ScreenOffDrama](https://github.com/xiaoyudianbaba/ScreenOffDrama)：与本工程方案几乎一致（纯黑悬浮窗 + 不抢焦点 + mediaPlayback前台服务），差异点在于它用无障碍服务做YouTube广告自动跳过。本项目借鉴了它的"电源键退出遮罩"（监听 `ACTION_SCREEN_OFF`）。
- [Blackr: OLED Screen Off](https://play.google.com/store/apps/details?id=com.neximolabs.blackr)（百万安装）：同为纯黑遮罩方案，佐证这是免root场景的行业标准做法。
- [sothx/mipad-hyper-hangup_while_screen_off](https://github.com/sothx/mipad-hyper-hangup_while_screen_off)：小米平板HyperOS的Magisk模块补全"熄屏挂机/听剧"——真息屏的系统级实现需要root，OPPO解BL基本不可行。
- V2EX讨论（MIUI 14无息屏听剧）：社区提到酷安"熄屏挂机"工具用Shizuku(shell)/root实现；本项目用免root的 `dispatchMediaKeyEvent` 达到类似效果。
