## 发现与修复

1. **旧暂停回调污染新会话**：结束后的5秒内开启新会话，旧播放器回调曾按当前ID更新。改为捕获结束时ID，只精化该条历史；取消观察也结算为未确认。原生用例验证新会话保持NONE，原条变为confirmed。
2. **系统时间回拨丢失摘要**：将外部导入未来时间校验与本地已验证记录区分；结束墙钟早于开始时保留未知结束，不伪造时间。`clock-red.log`曾194项中1失败，修复后完整196通过。
3. **唤醒锁自动超时后诊断仍显示持有**：按实际配置的超时封顶，幂等释放不重复累计；纯规则回归通过。
4. **恢复提示覆盖成就详情**：API33完整核心序列抓到活动窗口实际为Restore history。增加本地历史/结果/待收数据检查及焦点/生命周期复查，备份查询移到后台。修复后同序列14项通过；保留`achievement-detail-failure.txt`和失败日志。
5. **并行冷启动与短定时测试干扰**：旧核心亚秒deadline夹具在三个模拟器与release构建并行时失败；日志显示冷启动已超过夹具deadline。保留原断言，改为串行执行，API26/35通过；未据此放宽生产定时策略。
