# v5.1.5 当前播放来源识别修复与验收

## 结论

- OPPO PME110/API 36 上复现：通知使用权正常，抖音实际有媒体音频活动，但其活跃 MediaSession 上报 STOPPED；原策略只接受唯一 PLAYING，因此黑幕提示无法确定来源。
- 已补充 API 33+ 的系统媒体按键目标信号，并与媒体音频活动同时检查。未新增权限、手动播放器选择或诊断入口。
- 系统路由不是逐应用音频归属证明。状态不可靠的会话仅显示“可能来自 [应用名] · 请返回视频操作”，不显示旧标题、不开放媒体控制或暂停定时。黑幕和撤幕定时仍可用。
- 完全不提供可用媒体会话、或系统仅保留旧媒体目标的 App，仍不能保证准确识别。没有将本次结果标为全 App 兼容通过。

## 改动

1. `PlaybackSources` 同一快照采集 active sessions、系统媒体目标与音频活动；旧系统/API不可用时保持原逻辑。
2. `CurrentPlaybackPolicy` 可识别有音频活动且被系统路由到的 STOPPED/NONE 会话；不因全局音频活动把 PAUSED 历史播放器提升为来源。系统目标可覆盖其他 App 残留的 PLAYING 状态。
3. `NowPlaying` 区分来源提示和可靠控制能力；不可靠状态不使用标题、seek 或媒体控制。有效时长缺失时也不显示 seek。
4. `TimerPlaybackTarget.canArm` 排除 STOPPED/NONE/ERROR，避免以已停止状态误承诺暂停能力。已受理定时仍保留原会话目标。
5. 黑幕与两种定时入口使用相同的不确定来源提示，八种语言均已更新；版本号为 5.1.5/code94。
