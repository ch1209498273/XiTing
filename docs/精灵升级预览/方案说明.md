# 精灵视觉与动画升级提案

本文保留 2026-10-11 的设计提案；其中“当前源码观察”描述改造前状态。后续已接入 Android，最新实现与验证见《接入与验收.md》。本文 SVG/PNG/GIF 仍属于设计样片，实际渲染证据见 Android实际绘制.png。

目标：让五阶精灵成为同一套有亲和力的角色，动作有明确节奏；统计页、悬浮球、图鉴、小组件与分享海报保持身份一致。

当前源码观察：

- PetView 的五阶分别采用尖星、圆球、云、圆堆风暴、尖星与光环；面部尺度与主体关系不统一。这是设计判断，不是用户测评数据。
- PetView 常驻约 33ms 重绘，BubblePetView 使用 100ms 间隔。时间间隔可从源码确认，但未做帧耗时或卡顿实测，不能把视觉体验差直接归因于设备性能。
- 摸头主要改变表情并上浮爱心，缺少整体压缩、预备动作和回弹；新样片增加这些阶段。
- onTouchEvent 的未移动 ACTION_UP 入口先调用 performClick，后续未命中分支又调用一次；点击能量条或帮助也会先触发 onClick。正式接入时应划清交互命中，避免重复点击事件和摸头抢占其他操作。
- 当前工作区有用户已有改动，其中包括 PetView；正式实现前须重新读取差异，只改本次渲染与交互相关部分。

推荐方案：圆润电能伙伴。按用户最新反馈，增强每次进化的差异，不以换色作为主要升级表现。闭合轮廓、统一小眼睛与低位面部、中等饱和度实体颜色、克制高光。保留现有五阶 ID、成长阈值、皮肤 ID、成就与备份数据。

| 等级 | 形态变化 | 专属动态特效 |
|---|---|---|
| Lv.1 电火花 | 最小的火种，尖顶、无四肢 | 暖色火星错峰上浮 |
| Lv.2 电球 | 更大、更饱满的圆团，长出小手臂 | 向外扩散的充能波纹和绕行能量点 |
| Lv.3 雷云精灵 | 横向展开为三团云，底部闪电结构 | 云下短闪电错峰浮现，云边轻摆 |
| Lv.4 风暴之灵 | 上部云冠、下部收束为弯曲旋流尾，增加风带 | 前后交错的旋流轨迹和沿轨风粒 |
| Lv.5 雷霆之王 | 最大的实体，双翼、小脚、耳尖与金冠 | 羽翼缓慢扇动、金色星辉环绕 |

本次样片：各阶以 0.65/0.80/0.93/1.04/1.12 的相对尺寸绘制；这是预览比例，正式接入需根据能量条、徽章和触摸区调整实际几何。小头像应优先保留轮廓和标志结构，不照搬全量粒子。困倦时特效收弱，摸头时适度增强；不使用全屏闪白或高频闪烁。

正式实现的进化过渡建议：旧形态微缩 → 能量向内汇聚 → 新轮廓展开并回弹 → 新等级特效亮相；建议总时长约 0.8–1.2 秒，仅在真实进化时触发一次。此进化过渡尚未制作或接入，当前 GIF 展示五阶各自的待机、摸头与困倦状态。

可选方向：如果希望更冷酷，可增强眉眼与轮廓力度，保留动作时序；如果希望更安静，可降低浮动和回弹幅度。不要先接入多个美术风格再让用户选择，以免不同页面出现多套角色。

动效：待机轻呼吸和错峰眨眼；摸头压缩→弹起→阻尼回弹，表情与爱心延后；困倦慢呼吸和闭眼。生产实现还要补充实际状态切换过渡、减弱动态、不可见停帧与系统动画关闭支持。GIF 只是循环样片，不能证明 Android 动画流畅或省电。

实现范围：PetView 与 BubblePetView 的本体绘制和时序，必要时提取共享渲染器；图鉴、小组件、海报的静态角色由相同几何生成。检查所有调用方后再定提取范围，避免同时保留两套轮廓。

验收：同阶大图与小头像一致；五阶在缩略图下可辨认；浅色与深色背景清晰；六套现有皮肤可用；摸头不抢帮助与能量收集；页面不可见和黑幕遮挡时停帧；构建及相关现有测试通过，并在可用设备上查看真实动作。没有实机条件时明确保留未验收项。
