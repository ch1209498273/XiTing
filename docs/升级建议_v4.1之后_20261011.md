# v4.1 之后：升级建议

2026-10-11，基于当前源码和项目决策的产品评估。没有新用户调研、留存统计或真机耗电测量；下面的用户价值是待验证判断，成本为相对工作量，不是工期承诺。本次不实施功能变更。

建议围绕两个目标：让用户第一次就能成功黑幕听剧，以及让精灵成为轻量的陪伴。保留本地、轻量、无 INTERNET 权限的产品定位。

## 建议版本顺序

小修版本：先修图鉴提示与对外文案，给出可复现前后例子；原有成长与备份数据不变。

下一次功能版：优先打通睡前定时的结束动作、首次使用闭环和精灵互动预览。这三项分别服务主场景、首次成功和这次宣传卖点。实际进化转场可放随后的小版本，避免为了展示效果跳过核心体验验证。

养成数值与过期规则先做方案讨论；200 上限/3天过期是现行契约，不在一次普通视觉改动中静默调整。省电与兼容性测试持续进行，测试结果只能推广到测过的环境。

## 如何验收

- 图鉴：0、29、30、299、300、1499、1500、5999、6000成长值分别核对锁定/下一阶剩余值；切回低阶展示不改变进度口径。
- 定时：目标播放器播放/暂停、多个媒体会话、通知使用权未授予、暂停动作不支持时逐项检查；到期不意外亮屏，不把暂停改成播放。Android 提供 pause() 请求并不保证第三方播放器一定响应。
- 新手闭环：邀请未参与开发的人操作，记录卡在哪一步、能否完成第一次黑幕与恢复；以观察结果验证建议，不预先宣称留存提高。
- 精灵预览：未解锁可以演示，退出后成长值、佩戴形态和皮肤状态不变；实际跨级转场只播放一次，关闭系统动画时可用。
- 性能：相同设备/场景看页面帧耗时和隐藏停帧，不以模拟器检查代替真机耗电结论。

## 明确排除

项目已决定不做 OCR 黑幕字幕、本地视频播放器、播放中断提醒；本建议不重新列为下一版需求。已有深色模式、多语言、桌面小组件、月报年报和本地备份不重复当新功能。也不建议为了“留存”先加入账号、社交排行、签到打卡与服务器推送，避免偏离轻量听剧工具的目标。

## 外部核对

- [Android WindowManager.LayoutParams](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#BRIGHTNESS_OVERRIDE_OFF)：最低背光亮度的窗口设置，不单独证明系统关屏或所有硬件背光关闭。
- [Android MediaController.TransportControls.pause](https://developer.android.com/reference/android/media/session/MediaController.TransportControls#pause())：可以向媒体会话发送暂停请求；第三方播放器支持情况仍需实测。
