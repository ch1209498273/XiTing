# v6.2.1 更新说明

- 「常用入口顺序」只列首页当前可见的入口。完成首次引导后，「演示」会从排序列表隐藏。
- 发版脚本在 Gradle 任务完成后关闭守护进程，单测或 lint 失败时会在写入新版本号前停止。

Android 35 模拟器已复核首次引导前后的排序列表。优酷一分钟暂停并保留黑幕的 OPPO 真机补验使用 v6.2.0，见 [真机补验记录](v6.2.0.md)。

版本号为 6.2.1，versionCode 为 102。官方下载位于 [GitHub Release](https://github.com/ch1209498273/XiTing/releases/tag/v6.2.1) 和 [蒲公英](https://www.pgyer.com/xipingtingju)。
